Defensa de Arquitectura (IE7)

Pipeline RAG con índice local y API documentada

Ingesta e indexación
1. Corpus del proyecto: 10 procedimientos + 30 FAQ
↓
2. RecursiveCharacterTextSplitter (200 / overlap 20)
↓
3. mistral-embed mediante la API de Mistral
↓
4. Índice Vectorial FAISS (Persistencia local)
Consulta e inferencia
1. Consulta desde la consola Rich
↓
2. Embedding configurado → búsqueda FAISS (k=3)
↓
3. RetrievalQA: contexto recuperado + prompt
↓ servicio de generación configurado
4. ministral-8b-latest → respuesta y trazabilidad
Alcance de infraestructura: El perfil documentado usa la API de Mistral para embeddings y generación. El proveedor y el endpoint se configuran por entorno; FAISS y sus metadatos se persisten localmente.

Instrucción de abstención en el prompt

  • Las 41 consultas registraron tokens y llegaron al modelo.
